# August operating model

August is a product built on top of the OpenCode codebase. The local branch `next` is the main August integration branch.

Remotes:

- `origin`: `https://github.com/33may/opencode.git` — August fork, push here.
- `upstream`: `https://github.com/sst/opencode.git` — official OpenCode, fetch/merge only.

Rule: upstream is an input stream, not the source of truth for August decisions.
