# AugustResearch Bootstrap Fixture

This tiny project exists to validate AugustResearch artifact creation and bounded prototype behavior.

The project has one editable config file, `research-target.json`. A successful validation run should research at least two approaches for enabling the placeholder feature flag, critique the options, make one safe prototype edit to that config, and write the `augustresearch/` bootstrap notebook.

Protected files for the validation run:

- `README.md`

Editable files for the validation run:

- `research-target.json`
